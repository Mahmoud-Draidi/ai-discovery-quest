## Independent mini-lessons

Open Learning journey → Browse mini-lessons to search individual practical activities. Each activity has its own availability, observation and outcome. Existing chapter exercises share their original practical check; the new optional activities have separate records and award no XP. Fallback reviewed means the tool remains untried. Earlier combined checks are preserved, but never inferred as completion of the newly separated features. Chapter counts, quizzes and final completion stay on the chapter route.

## Honest progress

The app records your report; it cannot observe external chats or files. A chapter earns 100 XP only after all exercises and knowledge questions are complete, Questions & sources has been reviewed, and the learner uses Mark chapter completed from My note. Level titles reflect the percentage of current chapters completed; viewing pages, repeating answers, skipping steps and writing observations do not earn XP. If tools are missing, defer the individual step and explore another. Deferred/skipped steps stay unfinished; completion requires every practical check.

## Study support

Use Terms & definitions inside a lesson, or select a dotted term, to open a short definition and course example. Close it to return to the same focus and reading position. Coding, GitHub and environment chapters include a clickable worked tracker example comparing working files, staging, local commits and GitHub through a PR and merge. It runs no commands and awards no credit. Recovery requests cover a ZIP download, missing tools, author identity, the wrong folder, failed pushes, conflicts and fresh-chat handoffs. Memory includes five source/scope comparison cases without requiring account switching or changes to automatic memory settings.

Practices lead with one message to send and a result to check. Preparation and working examples are tucked under Before you start; the first foundations activity has an optional example answer after the task. Repeated generic role instructions are omitted. Practice-only time estimates exclude setup and waiting. Use Need help to expand recovery, or Unavailable on my account to preserve the exercise for later without losing other completed work. Optional per-exercise observations save locally. Use the compact companion from Try it to keep the current step, inputs and expected result visible beside your AI tool. The companion can stay on top and synchronizes its checkbox with the main lesson; only the main app saves progress. Use Next step to explore without claiming completion, My chapter note to return to the main note editor, or Return to lesson. Practice-step buttons let you revisit unfinished work directly. Overview separates Resume from a recommendation based on recorded preparation and per-exercise availability. Revisit later lists postponed exercises with recovery guidance and exact return links. Availability can be Unknown, Available, Needs setup or Unavailable; it is separate from work already completed. Equivalent preparation is explicitly learner-reported and grants no completion credit. Common question expansions persist across visits; all questions must still be expanded to continue. Use chapter questions/sources, library search and topic filters, and your notes when returning.

## Worked workflow labs

Matching advanced exercises expose a collapsed Guided workflow lab. Its small steps include setup, a prepared request, an illustrative intermediate result, a check against your actual result, recovery and cleanup. Related examples are selectable on Understand; Try it stays tied to the current exercise. Guide positions survive restart and backup/import without marking any exercise done.
