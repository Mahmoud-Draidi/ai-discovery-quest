# Learn ChatGPT by using its features

Current writing inventory: 2026.10.27-feature-journey-all-drafted. 64 tutorials written; 0 topics still to write. This is an unreleased curriculum rewrite, not a finished or live-client-validated course.

Open Learning journey to choose a capability. Each tutorial explains its purpose, directs actions in the actual app, names an outcome to inspect and provides an independent task. Tutorials vary in length and activity; they are not a repeated request to ask another AI to teach the topic.

Reading steps or copying a request does not mark practice. You record practice after trying the feature and checking the outcome. Availability, notes and reading position are saved independently for each tutorial. Earlier chapter records remain separate.
